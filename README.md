# Entropon Decelerator

This Arduino Nano 33 IoT project lies at the heart of the [Entroponics™](https://entroponics.com) exhibit presented at the Holistic Quantum Activation Art Expo, arranged by the <a href='https://www.instagram.com/starstuffsocietyphilly/'>Starstuff Society of Philadelphia</a>.

![Entropon Decelerator](https://entroponics.com/resources/mk2/familyphoto.jpg "Entropon Decelerator")

The exhibit consists of a “deceleration chamber” that purports to allow a visitor to experience a localized slowdown of time. To visualize this, this Arduino project drives a series of displays – one on a larger "control unit," and one on a smaller "chamber unit," each run by an Arduino Nano 33 IoT linked to the other via serial – showing the inside time of day gradually falling behind the outside time. Buttons and knobs control the session state, and at the conclusion of the session, data is sent to a thermal ticket printer to print a certificate of completion.

[Hardware details for this project are available here.](https://entroponics.com/decelerator/)
